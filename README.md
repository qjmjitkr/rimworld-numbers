## 📖 About

🔹 **RimWorld — Numbers** is a powerful tool built to help you view detailed numerical statistics for all your RimWorld colonists in a clean, sortable table. Numbers displays every stat, need, skill, and trait for all colonists in one organized panel for easy comparison.

🔸 Whether you're a seasoned professional or just getting started, **RimWorld — Numbers** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their RimWorld modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Stat Tables | Sortable columns for every skill, stat, need, and trait |
| Custom Columns | Add or remove data columns based on what matters to you |
| Color Coding | Automatic color indicators for stat levels across your colony |
| Export Ready | Copy stat tables to clipboard for external analysis |
